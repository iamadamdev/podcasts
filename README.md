# Custom generated podcasts

A small, static podcast site published with GitHub Pages.

- Site: <https://iamadamdev.github.io/podcasts/>
- RSS feed: <https://iamadamdev.github.io/podcasts/feed.xml>

The RSS feed and web players use 96 kbps MP3 copies in `audio_files/`, hosted
directly by GitHub Pages. The original M4A files are also available as GitHub
Release assets because each source file is larger than Git's 100 MB per-file
limit.
