# Custom generated podcasts

A small, static podcast site published with GitHub Pages.

- Site: <https://iamadamdev.github.io/podcasts/>
- RSS feed: <https://iamadamdev.github.io/podcasts/feed.xml>

The RSS feed and web player use a 96 kbps MP3 copy in `audio_files/`, hosted
directly by GitHub Pages. The original M4A file is also available as a GitHub
Release asset because the source file is larger than Git's 100 MB per-file
limit.
