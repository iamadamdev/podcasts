# Custom generated podcasts

A small, static podcast site published with GitHub Pages.

- Site: <https://iamadamdev.github.io/podcasts/>
- RSS feed: <https://iamadamdev.github.io/podcasts/feed.xml>

The original audio files are kept locally in `audio_files/` and published as
GitHub Release assets because each file is larger than Git's 100 MB per-file
limit. The RSS feed and web players link to those public release assets.
